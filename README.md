# Shooting Range

Shooting range video game made by Unreal Engine 5. 

This app was created according to the requirements of kood/Jõhvi: https://github.com/01-edu/public/tree/master/subjects/gaming/firing-range

Since the project size is too big to upload here, the whole project is stored here: https://illuminatekmkz-my.sharepoint.com/:f:/g/personal/yuki_k_illuminatekmkz_onmicrosoft_com/IgDs1kQkO3fLSa_GzJHLvR9vAcHuKgmIZrsm12gIVgYIasg?e=VE9CUK

## Used Assed

I used a lot of third party assets provided on Fab market place. Most of models and animations are not made by me. Check the list of downloaded assets in `Content` directory.

## Installation & How to Play

To play the game, you need to package the game in UE for your platform (I only tested in Windows).

You can check the test play video: https://youtu.be/lgHv_C8b5fM?si=SVxwOV-s5ja5K83V
